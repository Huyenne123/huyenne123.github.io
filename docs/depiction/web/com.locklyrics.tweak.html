1.0.0

Initial release: Real-time synced lock screen lyrics with LRCLIB, lrc.red, and Musixmatch support, MediaRemote true elapsed-time synchronization, customizable positioning, and live draggable interface.

1.1.0

Added SpicyLyrics provider support (developers.spicylyrics.org API key) with syllable and line level sync.

1.1.1

Fix stuck/joined words on SpicyLyrics syllable-level sync by honoring the IsPartOfWord flag and word spacing boundaries.

1.2.0

Added a Y Position slider with a live interactive Lock Screen preview in Settings (supports tapping the preview, center-snap haptic guide, and live syncing with presets, line count, and font size).

1.2.1

Fixed Settings crash on iOS 18 arm64e caused by NSNotificationCenter/Swift Foundation bridging in the Lock Screen preview.
